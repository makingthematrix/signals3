Closeable

io.github.makingthematrix.signals3.Closeable
See theCloseable companion object
trait Closeable extends AutoCloseable, CanBeClosed

A stream or a signal can be closeable, meaning that it can be closed and after that it will not publish new events anymore. Every generators.GeneratorStream and generators.GeneratorSignal is Closeable which allows for stopping them when they're no longer needed, but you can make any new stream or signal inherit Closeable and implement the required logic. Closeable extends java.lang.AutoCloseable so in theory it can be used in Java try-with-resources.
